# 岩芯样本切片实验室 · 切片交接与污染隔离台

运行：

```bash
npm start
```

访问 `http://localhost:3025`。

在原有的样本创建、切片制片步骤、交付统计之上，扩展了切片保管链与污染隔离：

- **领取**：在库切片可被领取，记录责任人、位置与温控时限（默认 240 分钟）。同一时刻同一笔数据库写入串行化，重复或并发的多笔领取只成功一笔。
- **制片**：记录制片步骤时核对操作人必须是当前责任人，并同步刷新当前位置。
- **交接**：记录交出人、接收人、交接位置；同一片只允许存在一笔未归还交接，归还前不能再次交接。
- **归还**：必须由当前登记责任人（若有未归还交接则为接收人）发起，并勾选确认密封完好；责任人不符或密封异常一律拒绝（密封异常请走隔离）。
- **污染 / 温控超时隔离**：已登记污染、超过温控截止时间或处于隔离中的切片，领取、制片、交接、归还全部被阻断，只能进入隔离复核；位置变为隔离复核区并记录复核责任人与原因。
- **解除隔离**：复核登记后切片回库，密封重新确认，原领取/制片/交接/归还原流程恢复；污染原因与全部位置历史作为只追加事件长期保留，刷新后仍然一致。

数据保存在 `data/core-slices.json`，旧数据在服务首次启动时自动迁移（补全保管链字段并把历史制片日志转为位置历史）。
